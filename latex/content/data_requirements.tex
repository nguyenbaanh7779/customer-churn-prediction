The primary data source is the \textbf{UCI Online Retail II Dataset}. It contains transaction-level records with the following fields:

\begin{itemize}
    \item \textbf{Invoice} -- invoice/transaction identifier (cancellations are indicated separately).
    \item \textbf{StockCode} and \textbf{Description} -- product identifier and description.
    \item \textbf{Quantity} -- number of units purchased in the transaction line.
    \item \textbf{InvoiceDate} -- timestamp of the transaction.
    \item \textbf{Price} -- unit price.
    \item \textbf{Customer ID} -- customer identifier (not always present).
    \item \textbf{Country} -- customer's country.
\end{itemize}

Customer, transaction, product, and time information from these fields are used to build each customer's purchase history and behavioral features.
